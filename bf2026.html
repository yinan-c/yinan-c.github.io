今年黑五我买了啥

每年黑五和赛博周一都会有大批软件软件打折。但由于 AI 辅助编程的出现，制作一个软件的成本很低。一方面对于普通用户而言，用编码实现自己想要的功能的门槛变低了；另一方面大量 AI slop 充斥了互联网，他们千篇一律的主页和软件设计，大段机器人味儿的销售话术，都在透露这个开发者是否用心，以及让人怀疑他是否有能力或者有意愿继续维护这个软件的开发。并不是说 AI 辅助编程或者 vibe coded 软件没有质量好的，只不过消费者要更加擦亮双眼，握紧钱包了。

这里推荐几个我在黑五推荐购买的一些软件。

  1. Notebooks: 黑五 7 折，08 年就在 App Store 的老牌笔记软件，并且大版本更新可以继续用上个版本的 license。之所以吸引我是因为它和 Obsidian 一样的本地优先，文件按照软件内的树结构存在本地，但比 Obsidian 好的点是可以存放和预览甚至编辑各种文件，包括 Keynote, Office Suite，pdf，之前用 Obsidian 的时候总是无法很好的处理 docx 文件。
  2. LicenseStore: 黑五半价，Apptorium 开发的软件，用来存放购买的软件 License，比 1Password 好用，可以推荐。
  3. Alfred: 应该是不会打折的，2023 年买了 PowerPack 以来平均每天打开 150 次的软件，在我看来使用速度和体验远超过 Raycast 和 Spotlight。最近更新了 Alfred UI toolkit，可以自定义 workflow 的界面。
  4. Things 3: 黑五 7 折，非常推荐的 Todo app。
  5. Unfold: 好像是没打折，之前双十一在数码荔枝买的，Quicklook 的软件，可以看 Tex，ePub 等文件。
  6. WorkingCopy: 黑五打折，是一个移动端的 Git 客户端，之前 Obsidian，现在 Notebooks 的 iOS 都用这个通过 GitHub 和电脑同步。
  7. Secure ShellFish: 黑五打折，和 Workingcopy 是同一个开发者，特点是可以 SSH 远程服务器/mac/nas 以及用 SFTP 把文件以网盘的形式挂载到 iOS 的文件系统。

黑五还未结束，这篇文章在接下来几天可能继续更新，也欢迎分享你推荐的软件。
